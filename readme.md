# Competitive Programming

This repository holds my solutions and templates for competitive programming problems. Text and identifiers may be in english or portuguese.

## File Structure

Files are organized by context and not platform.

*   `contests/`: Sets of problems in a competition style, usually with a time limit to complete.
    *   `live/`: Competitions that I participated officially.
    *   `virtual/`: Competitions I didn't participate officially, but simulated the official rules.
    *   `mashups/`: Dinamically generated contests for practice.
*   `practice/`: Problems solved outside of a competition environment for practice.
    *   `upsolving/`: Upsolving of problems I've done in `contests`.
    *   `cses/`, `usaco/`, ...: Problem sets grouped by origin.
*   `setup/`: My templates and files related to the environment.
